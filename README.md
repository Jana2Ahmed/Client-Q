# رِواق القهوة — Client-Q
نموذج عربي للمتجر ولوحة صانع الأسئلة الشائعة.

شغّل `python3 -m http.server 8000 --directory dist` ثم افتح `http://localhost:8000`.
المتجر: `#/store` — التاجر: `#/dashboard`.
لا يحتاج مكتبات أو مفتاح ذكاء اصطناعي. الاختيارات محفوظة في localStorage للمتصفح نفسه فقط. لا توجد مصادقة أو عمليات شراء.
البيانات والصور مصطنعة من حزمة masar-demo-store؛ لا تُستخدم الصور لإثبات المواصفات. لا تُضمّن سجلات العملاء أو الطلبات أو نصوص المراسلات.
تشغيل اختبارات المنطق: `node tests/faq.test.cjs`.
